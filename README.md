# Acme Trading · Certificado de recompensa (demo)

Propuesta de rediseño de una página de certificado de recompensa para **Acme Trading, una marca ficticia**.
Todos los datos (nombre, monto, firma, código) son de ejemplo y la página no verifica nada.

- `index.html`: página estática, sin dependencias de build.
- Deploy: Vercel publica automáticamente cada push a `main`.
